| S01 | “新增技能”生成独立记录，不接等级链 | 技能页增加“追加下一级”、图标和等级链预览 | 1245→1246 / Type24 / Lv6，继承效果费用供手动改；拒绝非链尾/重号/重复等级 |

## 2. 真实资源关系结论

1. **科技树不是逐条独立数值表。** Categorys、Position、升级目标和前置关系共同控制图的组织；布局决定容纳范围，图集/字符串/字体决定显示。两个不同 Type 同格是原游戏特性。
2. **坐标方向有旧资料歧义。** 外部 Excel 注释写“横向列、纵向行”，但真实数组第一项 1–4、第二项 1–10，而模板只有十列五行。本节点按 `[行,列]` 使用，并在操作文档明确说明，最终像素与点击仍需游戏核对。
3. **原表自带一条缺失目标。** Id305062 的 UpgradeID305063 不在表里，预览正确报告。无授权依据去改变原版语义，保留数据并标为来源诊断。
4. **钢铁洪流是 Type24 的等级链。** 1241–1245 是五级，1246 可用；追加 Lv6 延伸现有 Type，不增加第六个技能槽，也不发明效果公式。
5. **APK缓存不是完整安卓解包工程。** 它保存 assets/lib 供读取，APK原包保留其他内容；输出是资源覆盖目录，不是已签名安装包。

## 4. 剩余实机验收

- Windows：首页APK文件选择、提取进度/取消、已有输出重开，解包项目入口保留；输出目录默认名称、非空或来源不符报错。
- Windows：科技图实时更新、分组/布局切换、双图标分别选中、无效输入和越界诊断、PNG导出；布局编辑并保存后重开科技页。
- Windows：兵种/精英/特性/等级入口；技能搜索钢铁洪流→选择Lv5→追加→改效果/费用→保存→重载。键盘焦点、窄窗口和未保存提示。
- Android：外部重建/签名后，科技新增节点布局/升级/费用和新旧存档；技能Lv6的升级按钮、效果、等级展示、存档重启。数据重读成功不代替这些结果。
