## 2. 一并修正的问题

- 数据审计原来把 Type 3 NPC 的 `SkillsMax=0` 当容量错误；本轮只对该已知组合放行，玩家/进修记录和实际布局超出仍检测。
- 能力图标按 0–5 的 Type 绑定，避免错误请求 `general_ability_6.png`；技能 Id=0 按空槽处理。
- 预览布局尺寸测量不加载仅存在于隐藏提示框的图片，避免将不存在的隐藏提示图当成当前页面缺图。
- 布局 XML 读取解码实体，避免连续保存把 `&amp;` 变为 `&amp;amp;`；虚拟 Repeater 格子补齐父节点，点击区域可以沿父节点裁切。
- 布局图片解析保留图集路径；同名背景优先常规 UI，预览和布局编辑器都能显式指定战区/UI 图集。
- 将领与技能的离页保存使用输入校验，技能追加/筛选/切记录也拒绝无效数字。数字控件在并排/标签切换时重载不清除无效文本。
- 预览切页释放位图、字体和计时器，避免窗口或取消导航留下后台预览计时器；图片缓存随资源版本更新。
- 技能文字按已核对的概率 Type 使用 `ActivatesChance`，装甲/舰队致命一击这类 `SkillEffect` 与触发概率并存的记录不再把效果倍率误显示为概率。
- PNG 导出拒绝游戏来源、修改输出和路径链接，独立于游戏覆盖写入。
