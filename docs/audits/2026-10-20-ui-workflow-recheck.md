## 4. Windows 重点复测

1. 地图画布按 `Ctrl+S` 后直接继续按快捷键；文本输入框编辑后保存再输入，确认焦点、光标和输入正常。布局字段不先点击其他控件，直接 `Ctrl+S`，重开核对最后输入已保存。
2. 修改后返回其他页面，选择“取消”；继续键盘编辑。画布上按住移动键后点工具栏再松开，地图不得持续移动；窗口切出/切回也应清理旧按键。
3. 科技预览切到其他类别，点更新、导出和调整连线开关，类别不应跳回；修改选中记录 `Categorys` 后则应跟随新类别。窄窗标签切换后预览仍可用。
4. 布局编辑保存网格/表单改动后重新查看预览，核对使用输出覆盖；损坏/移除相关表单时出现诊断，旧科技节点不能继续点击或导出。无效数字/数组输入也应禁用预览操作。
5. 科技 PNG 导出到独立目录应成功；选择来源、增量输出或指向来源的链接目录应拒绝，来源不得出现预览图片。
6. 输出变更选择一条记录后搜索到无结果，详情应清空；恢复搜索可重新选择。来源同路径为目录时显示“无法比较”，查看不修改任何文件。
