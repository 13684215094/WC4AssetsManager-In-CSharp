## 3. 操作说明

### 3.1 项目与保存状态

先在首页手动选择游戏目录、APK 或已有增量项目，进入项目后再打开编辑项。公共标题栏显示项目名称，鼠标悬停查看只读来源和增量输出路径。当前页支持文档保存时显示公共保存按钮，也可按 `Ctrl+S`。

保存状态反映当前页 `HasUnsavedChanges`。有草稿或无效输入时显示“有未保存修改 / 待修正输入”；成功保存反馈写入输出目录。它不是全项目字段级差异列表，也不承诺其他未打开页面的草稿已全部保存。国家页继续采用字段确认后立即保存的现有流程，页面已注明该行为。

普通数据页的 Tab/Shift+Tab 留给 WPF 焦点导航。地图自己的快捷键继续使用已有输入管理器，只有地图画布需要输入时才接收；工具栏、下拉框及文本输入不会统一套用地图按键。

### 3.2 将领、技能和跨页返回

1. 打开“将领编辑”，使用全部类型、Type=1、Type=3 或其他 Type 筛选。Type=3 保留“NPC / 其他用途”标注，不按名字去重。
2. 在“技能 / 勋章”标签查看技能卡片。点击“替换 / 等级”打开选择器，先搜索类型，再选择实际 Level/记录 Id。实际写入 `Skills` 的仍是技能记录 Id。
3. 用上移/下移调整数组顺序；“清空为 Id=0”保留空槽位置，“移除槽位”缩短数组，两者含义不同。原始 Id 数组输入继续保留。
4. 添加槽位时，对 Type=1 检查 `SkillsMax`；已有技能页仍负责技能升级链和布局容量诊断。追加钢铁洪流 Lv6 不会自动创建第六个技能槽，也不会自动替换将领的原技能。
5. 点击“编辑此技能”前继续执行保存/放弃/取消确认。进入技能页后可按“返回将领”恢复本会话内的将领筛选、选中和属性位置。

“仅当前草稿中修改的记录”比较 `GeneralSettings` 当前内容与本次加载/保存的基线；恢复原值后不再列入，保存后更新基线。它不包含仅 `def_portraitpos.xml` 位移的修改，也不表示相对最初游戏来源的全部输出差异。

技能选择器和说明卡复用项目名称、介绍与参数解析。简体/繁体/英语展示不等于同时修改三份本地化；技能文字编辑仍使用既有 `stringtable_tw.ini` 保存目标，本轮未增加语言文件迁移功能。

### 3.3 兵种特性与详情预览

`Feature` 引用 `ArmyFeatureSettings.Type`，`FeatureLevel` 与其按下标配对。选择器先选特性，再选当前项目已有等级，卡片展示实际介绍和参数；“编辑此特性配置”定位对应记录 Id。

若原兵种的 `FeatureLevel=[]`，选择器明确保留运行时等级。仅查看、替换特性类型、移动或移除槽位都不补造等级。需要指定等级时，先在原始数组输入处完整填写与 `Feature` 一一对应的 `FeatureLevel`，再使用逐槽等级选择。遇到原始数组数量不一致时显示具体数量，保留原始输入，先由用户明确修正再操作；不会自动裁掉多余项。

详情预览读取项目 `form_unitinfo`，显示名称、攻击范围、防御、移动、射程、HP 和六个布局特性按钮。静态图片按 `Army` 使用当前项目对应图标，找不到时显示诊断；不使用其他兵种补位。基础数值直接取当前有效草稿，不冒充将领、科技、编队和战斗状态叠加后的实际数值。

无效输入保留并阻止保存/导出，预览注明仍展示上次有效值。`FeatureLevel` 为空时，图标采用项目基础等级供参考，说明中标明未补写等级。点击特性区域可打开对应配置；跳页继续检查未保存修改。

### 3.4 国家与科技预览

国家页先选基础国家，再切“征服实例”选择具体征服记录。游戏 UI 根据该实例显示星级和阵营；国家旗帜来自当前项目。将领数量、外交、解锁及存档状态未绑定，预览不伪造这些数据。基础国家资料不会自行推断某一条征服记录。

总部科技支持“适应区域”“100%”“定位选中”，可分别关闭升级线或依赖线。同格双科技按各自实际卡片区域选中；空格及卡片外留白不会夹取到旁边科技。本轮没有增加拖动节点、自动修复断链或科技位置撤销功能，修改 `Position` 仍通过已有字段编辑。

### 3.5 输出变更窗口

在资源浏览器点击“输出变更”。窗口只枚举输出目录中的实际文件，排除项目清单，不扫描来源独有文件，也不把内存草稿伪装成已写输出。

| 状态 | 判断与用途 |
|---|---|
| 输出新增 | 来源没有同路径文件 |
| 输出覆盖（内容不同） | 来源有该文件，长度或 SHA-256 不同 |
| 与来源字节相同 | 长度和 SHA-256 相同；提示可核对冗余，不自动删除 |
| 无法比较 | 读取失败或比较期间文件发生变化，显示具体原因 |

比较在打开或手动刷新时后台执行，可按相对路径及状态筛选，选择条目查看两侧完整路径。关闭窗口取消扫描。输出中的链接目录被拒绝，不跟随链接遍历；比较操作不写文件、不重载编辑器或丢弃草稿。本轮未提供覆盖文件删除、恢复原始按钮或字段级合并。
