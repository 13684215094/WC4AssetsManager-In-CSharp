# 将领、进修与技能升级 UI 预览

实现节点：2026-10-13。基准为 `/home/j60100428/game/wc4/World Conqueror 4_1.30.0`。本篇追加到既有项目资料；目录、APK、增量输出规则继续见 [项目工作流](project-workflow.md) 和 [APK、科技与技能](apk-tech-skills.md)。

## 1. 入口与操作

首页先加载游戏目录或 APK，再打开项目内的“将领编辑”。右侧现在包含属性和游戏 UI 预览：宽窗口左右并排，右侧区域不足 820 像素时切换为“属性编辑 / 游戏 UI 预览”标签页。分栏可拖动。属性修改在约 180 毫秒后更新预览，不需要先保存。

| 预览模式 | 操作 | 数据来源 |
|---|---|---|
| 将领详情 | 选择将领，调整名字、Photo、品质、能力、军衔、Hp、Skills 或头像位移 | 当前将领草稿、当前技能解析器、所选项目图片和布局 |
| 进修阶段 | 选择“进修阶段”，再选择对应记录 Id | `GeneralPromotionSettings.json` 中 `BaseID` 对应当前将领的记录 |
| 技能升级 | 选择当前将领的技能，切换“技能升级” | 当前技能记录及其 `UpgradeId` 指向的下一条记录 |

预览中的技能可以点击选中。将领页的“编辑所选技能”打开对应 Id；技能页点击左右技能卡片会同步切换属性记录。“编辑进修配置”打开配置表并选中当前进修 Id；“编辑页面布局”打开当前布局文件及当前表单。离开有修改的编辑器仍会询问保存、放弃或取消；输入无效或保存失败时不能把草稿当成已保存。

当前没有进修记录的将领会收到明确提示，不创建虚构阶段。进修配置保存后，重新进入将领页查看效果。布局编辑保存后同样重新进入对应预览。

## 2. 预览绑定的内容

### 2.1 将领详情

使用项目 `layout.xml` / `layout_x.xml` 等文件的 `form_generalinfo` 和 `tpl_general_photo`，注入以下内容：

- 姓名、品质背景、半身像或已有头像；半身像位移/缩放读当前 `def_portraitpos.xml` 草稿。
- 步兵、火炮、装甲、海军、空军、行军六类能力，以及当前值和预览有效上限。
- 军衔图标和本地化名称；Hp 显示原始等级 `HP LvN`，不推算战场实际生命值。
- 技能图片、实际 `Level`、已占槽与可用空槽；点击后显示名称和格式化描述。
- 项目中的称号入口图标。配置中的普通预装勋章按 Id 查表；原项目全部将领 `Medals` 为空，不代表玩家存档没有装备。

图标编号对应能力 Type：行军 0、步兵 1、装甲 2、火炮 3、海军 4、空军 5。界面排列仍遵循当前表单的六个格子。

部分原始记录的能力大于 JSON 中的 `*Max`。预览用 `max(当前值, 配置上限)` 显示有效上限，属性栏仍保留原始值，**不改写 JSON**。这是一条显示规则，不能代替当前 APK 的原生行为验证。

星图最多画六颗，并显示完整数字；超过六星会提醒需要核对原生支持。星图尺寸、运行时姓名/军衔位置和窗口外框采用编辑器近似安排，不能作为游戏截图逐像素比对的基准。

原项目没有半身像时使用当前角色的圆头像；圆头像也不存在时才尝试当前角色的战术头像。没有用另一位将领的图片替换，也不生成半身像。缺少全部可用图片会显示诊断。

### 2.2 进修阶段

使用 `form_generalpromotion`，按选择的阶段绑定 `Photo`、`Evaluate`、六项 `*Max`、`Skills`、`SkillsMax`。能力展示该阶段上限，不把基础能力冒充已经进修后的存档能力。面板列出 `CostSword`、`CostSceptre`、`CostMedal`、`CostMerit` 和 `AdvanceID`。

预览检查进修链缺失、循环或归属其他将领，但不自动迁移技能、重置存档，也不根据消耗判断玩家是否可以进修。

### 2.3 技能升级

使用 `form_upgradeskill`。左侧显示当前 Id/Level；右侧显示 `UpgradeId` 对应的下一条记录，按钮费用取**目标记录的 `CostMedal`**。链尾 `UpgradeId=0` 时明确显示没有下一等级。能力类 Type 0–5 使用能力图标，其他技能使用 `image/general_skill/general_skill_{Type}`。

技能页默认预览繁体中文 `tw`，与现有名称/描述编辑的保存位置一致。`tw` 预览读取技能文本草稿；切换 `cn` 或 `en` 则读取项目对应语言文件，不能把修改 `tw` 当成已同时修改其他语言。将领页默认简体中文。

描述支持 `[#00FF00#文字]` 颜色片段、换行、`%%` 和常见单个 `%d`。零效果概率技能以及已核对的概率 Type（如舰队/装甲致命一击系列）代入 `ActivatesChance`，其他效果描述代入 `SkillEffect`。多个或未知参数保留占位符并提示，避免猜测全部技能的 native 格式参数。

## 3. 钢铁洪流新增第六级的例子

1. 从技能页选中钢铁洪流 Type 24 的链尾 `1245 / Lv5`，点击“追加下一等级”。
2. 工具克隆记录并连接 `1245.UpgradeId → 新 Id`，通常新 Id 为 `1246`；存在冲突时使用其他空闲 Id。
3. 自行设置新级 `SkillEffect`、`CostMedal`、`Score` 等，例如效果 30、目标费用 500。工具不提供默认平衡公式。
4. 点等级链中的 Lv5，右侧升级预览立即显示 Lv5 的 25 和 Lv6 草稿中的 30，以及 500 勋章；点击右侧卡片会选中 Lv6 属性。
5. 保存后只产生修改过的配置文件。需要将角色的固定技能改成新 Id 时，再回到将领页修改 `Skills`。

“新增技能等级”和“新增技能槽位”是两件事。设 `SkillsMax=6` 而布局仍为五槽时会报警；即使修改布局有了第六槽，也不能据此认定原生逻辑与存档已支持第六槽。

## 4. 字体、图片与布局诊断

字体从项目 `font_resource.xml` 解析，支持 `PHONE/HD`、`PAD/HD`、`PAD/SD` 字号配置和 `cn/tw/en` 字体。本选项改变字体参数；当前使用 HD 美术，不完整模拟手机/平板分辨率、安全区域和设备缩放。

| 诊断 | 处理原则 |
|---|---|
| 图标、图页或字体缺失/损坏 | 显示文件/图片名与原因；字体允许回退，不隐瞒回退 |
| 同名图块尺寸不同 | 优先 HD 和常规 UI 图集，报告选中来源；可用 `image/图集名/图片名` 指定图集 |
| Skill Id、UpgradeId、AdvanceID 不存在或有环 | 报告具体节点，不修补关联、不替换为其他数据 |
| 技能数量或 SkillsMax 超出布局 `rpt_skill.itemcount` | 保持布局真实槽位，报告超出部分；不自动扩大布局 |
| NPC 的 SkillsMax=0、技能 Id=0 | Type 3 的内置技能预算零值不误报；Id=0 是空槽，不加载“技能 0” |
| 文本溢出 | 按区域裁切并提示；调整字号、换行或布局后重新查看 |
| 特殊勋带 Pic、未知文本参数 | 显式提示尚未绑定的规则，不显示猜测的装备/数值 |
| 无效数字、异常布局、模板循环 | 保留上一次有效输入提示或停止预览，阻止无效导出 |

展开限制为最多 12,000 节点、模板深度 64、Repeater 单组最多 128 项；画布最多 1,600 万像素。图片缓存随项目资源版本更新，并限制保留纹理页数量。窗口切页/关闭后释放位图、字体和更新计时器。

“更新预览”刷新资源缓存，同时保留编辑解析器的草稿；外部修改与当前草稿冲突仍在保存时检查。

## 5. 导出与保存范围

“导出 PNG”输出当前绑定后的完整静态预览，不包含编辑器选择框或诊断面板。输出位置必须在原游戏目录与修改输出目录以外，也拒绝通过目录链接绕回游戏路径。导出只生成审视图片，不写游戏 UI 资源。

预览绑定发生在布局的克隆及模板展开副本中，不把姓名、等级、占槽状态等写回源 XML。仅选择将领、切预览模式、调整预览语言/字号/缩放、查看 PNG **不会新增游戏覆盖文件**。游戏数据保存继续按增量输出规则进行。

## 6. 实现边界与验收

本轮实现静态区域预览，不包含完整游戏运行环境。动画、原生 Window 状态机、存档装备/勋带、实战数值、解锁状态和升级扣费仍需要 Windows 操作与 Android 实机核对；国家和兵种详情页预览也尚未接入。

真实资源样例生成在本机 `tmp/general-ui-preview/`：古德里安、隆美尔、朱可夫、朱可夫进修、只有头像的 NPC、钢铁洪流 Lv5→Lv6。图片由所选项目读取产生，不作为本仓预置美术发布。

完整测试、Windows 验收流程与本轮修复矩阵见 [2026-10-13 审计](../../audits/2026-10-13-general-ui-preview.md)。
